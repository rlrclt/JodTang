2. ลำดับการล็อกอิน (Google / LINE)

เส้นทางเดียวทั้งสองเจ้า · Better Auth ทำ state + PKCE + ตรวจ id_token ให้ · เคส LINE ไม่มีอีเมล (ยังไม่ขอสิทธิ์) ต้องผ่านได้

sequenceDiagram
  autonumber
  actor U as ผู้ใช้
  participant A as แอป (PWA)
  participant B as Better Auth
  participant I as Google / LINE
  participant D as Postgres

  U->>A: กด "เข้าสู่ระบบด้วย LINE"
  A->>B: signIn.social(provider: line)
  B->>I: authorize + state + PKCE
  I-->>U: หน้าขอยินยอม (LINE)
  U->>I: อนุญาต
  I-->>B: /api/auth/callback/line?code=...
  B->>I: แลก code เป็น token (server-to-server)
  I-->>B: id_token + userinfo (userId, name, picture, email?)
  B->>D: upsert user + account (provider=line)
  Note over B,D: email เป็น null ได้
emailVerified=false เสมอสำหรับ LINE
  B-->>A: session cookie (httpOnly)
  A-->>U: เข้าหน้าแรก
  alt ยังไม่มีอีเมล
    A-->>U: แถบ "เพิ่มอีเมลเพื่อกู้คืนบัญชี" (ข้ามได้)
  end

3. ตารางฐานข้อมูล

เงินทุกจำนวนเป็น bigint หน่วยสตางค์ บวกเสมอ (ห้าม float) · currency ล็อก 'THB' ด้วย check · งวดเดือนไทยเป็น generated column ที่ DB · ลบรายการ = soft delete · DDL จริงอยู่ที่ docs/schema.sql (v2)

Stack

  • • Next.js 15 App Router + TypeScript
  • • Tailwind CSS v4 (ไม่ใช้ไลบรารี UI)
  • • Better Auth → Google + LINE ในตัว
  • • Drizzle ORM + drizzle-kit migrate
  • • Neon Postgres — pooled / direct แยกกัน
  • • Vercel + PWA manifest/service worker

กติกาข้อมูล

  • • เงิน = bigint สตางค์ เสมอ
  • • timestamptz + timezone ผู้ใช้ Asia/Bangkok
  • • ลบ = soft delete (deleted_at)
  • • ทุก query กรองด้วย user_id
  • • LINE ไม่มีอีเมลได้ → email nullable

Native feel

  • • safe-area + bottom tab bar 4 แท็บ
  • • bottom sheet ไม่ใช้ modal กลางจอ
  • • คีย์แพดตัวเลขเอง · ปุ่ม ≥ 44px
  • • optimistic UI + haptic ตอนบันทึก
  • • skeleton ไม่ใช่ spinner · ไม่มี page reload
