### สิ่งที่เตรียมไว้แล้วสำหรับ 6.2 (เทียบได้ทันทีเมื่อรันได้)

อ่าน `docs/schema.sql` ครบแล้ว — 4 ตารางเป้าหมาย พร้อมคอลัมน์/ชนิด/nullable/unique/PK:

- **`user`** — `id` text PK · `name` text NOT NULL · `email` text NULL (check `= lower(btrim(email))`, `unique`) · `email_verified` boolean NOT NULL default false · `image` text NULL · `created_at`/`updated_at` timestamptz NOT NULL default now()
- **`session`** — `id` text PK · `expires_at` timestamptz NOT NULL · `token` text NOT NULL UNIQUE · `ip_address` text NULL · `user_agent` text NULL · `user_id` text NOT NULL FK→`user(id)` ON DELETE CASCADE · `created_at`/`updated_at` · index `session_user_id_idx(user_id)`
- **`account`** — `id` text PK · `account_id` text NOT NULL · `provider_id` text NOT NULL · `user_id` text NOT NULL FK cascade · `access_token`/`refresh_token`/`id_token` text NULL · `access_token_expires_at`/`refresh_token_expires_at` timestamptz NULL · `scope` text NULL · `password` text NULL · `created_at`/`updated_at` · UNIQUE(`provider_id`,`account_id`) · index `account_user_id_idx(user_id)`
- **`verification`** — `id` text PK · `identifier` text NOT NULL · `value` text NOT NULL · `expires_at` timestamptz NOT NULL · `created_at`/`updated_at` · index `verification_identifier_idx(identifier)`

⚠️ `docs/schema.sql` บรรทัด 32–35 เตือนเรื่องนี้ไว้แล้ว และล็อกทิศทางว่า **"ถ้าต่างกัน ให้ยึดผลจาก generate แล้วอัปเดตไฟล์นี้"** (ไม่ใช่แก้ฝั่ง drizzle ให้ตามไฟล์) — ผมจะยึดตามนั้น
